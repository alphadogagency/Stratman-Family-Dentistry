# Stratman Family Dentistry

Responsive Astro homepage draft for Stratman Family Dentistry in Tucson, Arizona. The Tucson Courtyard design uses the existing practice logo and photographs, with Oracle and Wilmot office contacts.

## Development

```sh
npm ci
npm run dev
```

The project pins Node 22.23.4 and Astro 7.4.5. npm scripts use the project-local Node runtime.

## Build

```sh
npm run build
npm run preview
```

The static output is generated in `dist/`, compatible with Cloudflare Pages. Build command: `npm run build`; output directory: `dist`; Node version: `22.23.4`.

## Review Status

This is a homepage draft awaiting review. Office phone numbers are provisional and require confirmation before launch. Draft indexing restrictions remain in the page metadata, `public/robots.txt`, and `public/_headers`; review them before an authorized production launch.

`DESIGN.md` documents the visual system. Image provenance lives beside the assets in `public/assets/`. Font licensing is included in `public/fonts/`.

Internal client briefs and agency working notes stay local and are excluded from this public repository.
